Smart Fall Detection System

Using YOLOv8 and CNN for accurate fall detection

About the System

Problem Statement

Falls are a leading cause of injury among elderly individuals. Our system provides real-time fall detection to enable quick response and assistance.

Technology Stack

YOLOv8: For real-time fall state detection (falling, not falling, sitting) with high accuracy.

CNN Classifier: For posture classification refinement when needed.

The combined model achieves 98% accuracy in our tests.
